# Умный планировщик задач

Учебный прототип из двух микросервисов (МДК 02.02, лабораторная работа №2).

- **Task Service** — создание, редактирование, удаление и получение списка задач.
- **Notification Service** — принимает событие о создании задачи и фиксирует уведомление.

## Правила работы с репозиторием

- `main` — защищённая ветка, изменения только через Pull Request с ревью.
- `dev` — ветка интеграции.
- `feature/*` — рабочие ветки, создаются от `dev`.
